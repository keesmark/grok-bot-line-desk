# Security Policy

日本語 | [English](#english)

## 脆弱性の報告

公開の Issue にはしないでください。リポジトリの **Security** タブ →「**Report a vulnerability**」から、非公開で報告してください。

見つけた内容、再現の手順、悪用されると何ができるかを書いてください。本物のトークン・送信キー・Webhook の URL・お客様のメッセージや名前は書かないでください。

## 対象のバージョン

最新の Release だけが対象です。修正は自動では届きません。修正が出たら、ボットに「更新はある？」と聞いてください。desk-update スキルが変更点を見せ、OK のあとで入れ替えます。

---

## English

### Reporting a vulnerability

Please do not open a public issue. Report it privately from the repository's **Security** tab → **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. Never include real tokens, webhook keys, webhook URLs, or customers' messages or names.

### Supported versions

Only the latest Release is supported. Fixes do not reach your bot automatically. When a fix is released, ask the bot 「更新はある？」. The desk-update skill shows what changed and replaces the scripts after your OK.
