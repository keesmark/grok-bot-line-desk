# 不在モード

バージョン：Desk for LINE v0.1.1

状態は、保存先（メモリの設定）と同じフォルダの `away.json` に置く：`{"away": true, "interval_minutes": <分>, "started_at": "<日時>", "last_bundle_at": "<日時>"}`（日時はタイムゾーン付き）。

## 始めるとき
1. まとめる間隔を聞く：「届いたメッセージは、どのくらいの間隔でまとめてお知らせしましょうか？」。数字はボットから提案しない。メモリの「不在モードの間隔」に前回の値があれば、「前回と同じ〇〇でよいですか？」と聞く。
2. 「まとめなくてよい」と言われたら、interval_minutes は null にする（まとめたお知らせはしない。一覧は、戻ったときか「未返信は？」と聞かれたときに出す）。
3. away を true にし、started_at と last_bundle_at を現在時刻にして書き込む。間隔はメモリにも書く。
4. 伝える：「不在モードにしました。届いたメッセージは記録して、〇〇ごとにまとめてお知らせします。急ぎのものには目印を付けます。」
   - null のとき：「不在モードにしました。届いたメッセージは記録しておき、戻ったときか『未返信は？』と聞かれたときに一覧でお見せします。」

## 不在のあいだ
- 受信のルーティンは1件ずつは通知しない。間隔が過ぎていれば、last_bundle_at より後の分をまとめて通知する。interval_minutes が null なら、まとめた通知もしない。
- 記録は続ける。送信はしない。既読もつけない。

## 戻ったとき
1. away を false にする。
2. `DESK_DB=<保存先> python3 -I /workspace/line-inbox/bin/list_unreplied.py --include-groups --json` で一覧を出す。【急ぎ】を先にし、そのあとは待ち時間の長い順に並べる。番号は付けない（返信は名前で言ってもらうため）。1件ごとに、誰から（`label`。`name_stale` の人は desk-inquiry-summary と同じ方法で名前を取得する）、用件、待っている時間、元の文の冒頭の「」引用を書く。`name_clash` の人には、desk-inquiry-summary と同じ注記を付ける。
3. グループ・複数人トークは要約だけにし、返信案は作らない。
4. 「ボットが把握している範囲です」と添える。返信は「〇〇さんに返信して」と言ってもらい、desk-reply スキルで行う。
- 一覧を出しただけでは既読をつけない。
