# 返信案と送信

版：Desk for LINE v0.1.0

- スクリプトは `/workspace/line-inbox/bin/` のものを `DESK_DB=<保存先> python3 -I` で実行（保存先はメモリの設定）。道具は `push_text_message`・`get_message_quota`・`get_profile` だけ。
- 承認・送信・定型文・名前・数字・キーワード応答の自動送信はメモリの「決まり」のとおり。

## 返信案（1対1だけ）
- 店の情報をもとに設定の口調と署名で書き、もとにした情報を添える。ないところは【要確認】。NGワード・大げさな言い方・売り込みは入れない。
- 定型文は `canned.py list` で探し、`canned.py fill <定型の名前> --var 名前=田中様 --var 日付=… --out <ファイル>`。使った定型の名前を添える。終了コード3（`unfilled: {日付}` など）なら社長に聞く。
- 返信案に進んだら `mark_read.py <最新の受信のid>`。
- 宛先の名前：`profile_cache.py get <userId> --json` の `label`。名前がないか `stale` が true のときだけ `get_profile` を1回呼び、一時ファイルに書いて `profile_cache.py set <userId> --name-file <ファイル>`、その名前に。読めなければ `label` のまま（「名前不明（ID末尾 xxxx）」）。返信案の頭に「〇〇さんへの返信案」と書く。

## 毎回出す2つの選択肢
> (a) 私が送ります（1通使います）
> (b) 社長がアプリから返します（0通。文面をコピーして、LINE公式アカウントアプリから返してください）

## (a) 私が送る
1. 先に見せる：宛先（表示名と元の文の「」引用）、全文、`get_message_quota` で読んだ今月の残り通数。(a)が続くときは「月の通数の上限」（設定にあれば）も伝え、「(b)なら通数を使いません」と添える。
2. 「送信 N」で1件ずつ（「OK」だけなら「何番を送りますか？」）。差し込みの値が変わっても見せ直す。「明日」など日付で意味が変わる古い案は作り直す。
3. `push_text_message` で、その1対1のuserIdに見せた全文のまま送る。
4. 文面を一時ファイルに書き（定型文なら `--out` のファイル）、`log_event.py --out --to <userId> --text-file <ファイル> --line-message-id <応答のID> --status sent`。結果不明は `send_unknown`。
5. 報告はAPIの応答のとおり（「〇〇さんに送りました」のように宛先の名前を添える）。結果不明なら「届いたかわかりません。アプリで確かめてください」と伝え、送り直さない。
   - エラーが返ったとき（例：文字数が多すぎる）：`--status failed --error="<エラーの要旨>"` で記録（送れなかった印。返信には数えない）。「送れませんでした。理由：〇〇。文面の先頭：「…」」と伝える。6はしない。自分で送り直さない。直すなら直した全文を見せ、新しく「送信 N」をもらう。
6. 送れたら `set_status.py <chat_key> 完了`、`mark_read.py`、`quota_check.py --json`。`notice_due` が true のときだけ今月の残り通数を伝える。

## キーワード応答の返事
- 一覧で見せた登録の返事に「送信 N」と言われたら `keyword_reply.py text <その件のmessage_id> --out <ファイル>`。見せた文と違えば見せ直す。そのファイルの文のまま(a)の3〜6（記録も同じファイルで `--status sent`）。

## (b) アプリから返す
- 「3は返した」と言われたら `log_event.py --out --to <userId> --status app_reply`、`set_status.py <chat_key> 完了`、`mark_read.py`。
- 見せた返信案のまま返したと社長が言ったときだけ、その文を一時ファイルに書いて `--text-file <ファイル>` も付ける。社長が自分の言葉で返したときは、文を作ったり推測したりして記録しない。

## 定型文
- 保存（言われたときだけ）：名前や日付を `{名前}` `{日付}` にした文と定型の名前の案を見せ、よければ一時ファイルに書いて `canned.py save <定型の名前> --text-file <ファイル>`。
- 「定型文を見せて」→ `canned.py list`、中身は `canned.py show <定型の名前>`。削除は確かめてから `canned.py delete <定型の名前> --yes`。
