# 不在モード

版：Desk for LINE v0.1

状態は保存先（メモリの設定）と同じフォルダの `away.json` に置く：`{"away": true, "interval_minutes": <分>, "started_at": "<日時>", "last_bundle_at": "<日時>"}`（日時はタイムゾーン付き）。

## 始めるとき
1. まとめる間隔を聞く：「届いたものは、どのくらいの間隔でまとめてお知らせしましょうか？」数字はボットから出さない。メモリの「不在モードの間隔」に前回の値があれば「前回と同じ〇〇でよいですか？」と聞く。
2. 「まとめなくてよい」なら interval_minutes は null にする（まとめてのお知らせはしない。一覧は、戻ったときか「未返信は？」と聞かれたときに出す）。
3. away を true、started_at と last_bundle_at を今の時刻にして書く。間隔はメモリにも入れる。
4. 伝える：「不在モードにしました。届いたものは記録して、〇〇ごとにまとめてお知らせします。急ぎの件は、まとめの中で目印を付けます。」
   - null のときは：「不在モードにしました。届いたものは記録しておきます。戻ったときか「未返信は？」と言われたときに、一覧でお出しします。」

## 不在のあいだ
- 受信のルーティンは1件ごとには知らせない。間隔が過ぎていたら、last_bundle_at より後の分をまとめて知らせる。interval_minutes が null なら、まとめても知らせない。
- 記録は続ける。送らない。既読もつけない。

## 戻ったとき
1. away を false にする。
2. `DESK_DB=<保存先> python3 /workspace/line-inbox/bin/list_unreplied.py --include-groups --json` で一覧を出す。【急ぎ】が先、そのあと待ちが長い順に番号を振る。1件ごとに誰から（`label`。`name_stale` の人は inquiry-summary と同じく名前を取る）・何の件か・待っている時間・原文の冒頭の「」引用。
3. グループ・複数人トークは要約だけ。返信案は作らない。
4. 「ボットが把握している範囲です」と添える。返信は reply スキルで、番号はこの一覧のものを使う。
- 一覧を出しただけでは既読をつけない。
